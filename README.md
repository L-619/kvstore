这是一个kv存储组件，支持数组，哈希，红黑树三种存储引擎，网络层包括epoll，Ntyco（github上的开源组件），通过宏定义可自由选择和扩展，比如还有io_uring可以添加
该项目由网络层，协议层，存储层，适配层，接口层，引擎层组成，可扩展性强。额外加入了内存池，哈希表的内存池还有点问题，实测红黑树的内存池可正常使用。
使用测试文件测得数组和红黑树未使用内存池时qps在33000左右，哈希表只有12000。使用内存池后红黑树的QPS上升到了37000，性能提升较为明显。

该项目可完善部分：
1.内存池只设计了固定块大小的，可以考虑做成不固定内存块大小的内存池。
2.跳表只实现了数据结构，还没有接入
3.网络层目前只考虑了单线程，后续可以增加锁，做成多线程，以及在网络层加入异步io_uring


自带makefile文件，执行make一键编译，kvstore就是可执行文件
